# O que é fermentação

::: info Texto de exemplo
Este artigo existe para mostrar a estrutura de `docs/`. Substitua pelo seu texto.
:::

Fermentação é o modo como leveduras e bactérias obtêm energia a partir de açúcares sem
depender de oxigênio. O que interessa à cozinha são os subprodutos:

| Alimento | Micro-organismo | O subproduto que importa |
|---|---|---|
| Pão | levedura | gás carbônico, que faz a massa crescer |
| Cerveja | levedura | álcool e gás carbônico |
| Queijo | bactérias lácticas | ácido láctico, que coagula e conserva |
